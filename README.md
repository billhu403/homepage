# Bill's Homepage

[Tomatoe](https://tomatoe.cc/)

## Tech Stack

- Astro
- React
- TypeScript
- CSS

## Commands

```sh
npm install
npm run dev
npm run build
npm run preview
```

The site builds to `dist/` as static files for GitHub and Cloudflare hosting.

## Cloudflare Pages

- Framework preset: `Astro`
- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `codex/astro-react-migration` while previewing, then switch to `main` after merging
- Node.js version: `22`
